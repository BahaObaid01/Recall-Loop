Start a fresh loop?

A simple loop. A clear goal.

  1. 01
    Answer one card at a time.

    Pick a choice, or use “I don’t know” to see the answer.

  2. 02
    Learn from what you miss.

    Wrong choices are marked without revealing the answer. Choose a maximum retry gap of 3, 7, or 10 other cards. With fewer cards left, retries return sooner. Changing card order during a session asks you to restart; changing the gap applies to future retries.

  3. 03
    Clear every question.

    Quick mode needs one correct answer per card. Reinforce needs two in a row for each card, with other cards between when possible.

Progress stays in this browser on this device. It does not sync across devices. Export your decks to keep a copy; exports contain questions, not session progress.

Install Recall Loop

Use Chrome or Edge on Windows. After installation, open it from your Start menu or pin it to the taskbar.

In Edge or Chrome, look for the install icon in the address bar. You can also find the install option in the browser menu. On iPhone or iPad, use Safari’s Share menu → Add to Home Screen.
